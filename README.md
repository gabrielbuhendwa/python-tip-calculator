# Python Tip Calculator

A command-line application built with Python to calculate restaurant bills, apply a tip percentage, and split the final amount evenly among a group of people.

## Overview

This project is part of my Python learning journey and focuses on implementing a practical calculation utility using core Python concepts.

The application collects the bill amount, the desired tip percentage, and the number of people sharing the bill. It then calculates the tip, determines the total amount due, and divides the final cost equally among the group.

## Features

* Calculate tips based on a user-defined percentage.
* Determine the total bill, including the tip.
* Split the final amount evenly among multiple people.
* Accept user input through a command-line interface.

## Technologies

* **Language:** Python 3
* **Interface:** Command-line (CLI)

## Getting Started

### Prerequisites

* Python 3 installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/gabrielbuhendwa/python-tip-calculator.git
```

Navigate to the project directory:

```bash
cd python-tip-calculator
```

### Running the Application

Execute the main Python file:

```bash
python main.py
```

Depending on your system configuration, you may need to use `python3 main.py` instead.
